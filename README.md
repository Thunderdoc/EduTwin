## 📱 What is EduFlow?

EduFlow is a revolutionary **autonomous learning platform** that uses behavior-driven intelligence to create fully personalized education experiences. Unlike traditional learning apps, EduFlow doesn't just personalize content — **it personalizes cognition itself**.

### 🎯 The Problem We Solve

Traditional learning apps require constant decisions:
- ❌ "What should I study?"
- ❌ "Which difficulty level?"
- ❌ "How much time?"
- ❌ "What next?"

### ✨ The EduFlow Solution

**One button. Zero decisions. Infinite learning.**

```
Click "Start Smart Learning" → AI handles everything
Learn → Test → Analyze → Adapt → Repeat (Automatically)
```

## 🧠 Smart Engine - 8 Advanced AI Systems

EduFlow's revolutionary **Smart Engine** features 8 interconnected AI systems:

1. **🧬 Learning DNA Profiler**
   - Creates unique cognitive fingerprint
   - Identifies your optimal learning patterns
   - Adapts to your mental model

2. **🎭 Cognitive State Modeler**
   - Monitors attention, fatigue, confidence
   - Adjusts in real-time to your mental state
   - Prevents cognitive overload

3. **🔄 Adaptive Strategy Switcher**
   - Switches teaching methods on-the-fly
   - Visual → Textual → Interactive
   - Finds what works best for YOU

4. **🔮 Future Path Simulator**
   - Predicts optimal learning trajectory
   - Simulates multiple paths
   - Chooses the most efficient route

5. **⚖️ Cognitive Load Balancer**
   - Prevents mental exhaustion
   - Balances difficulty dynamically
   - Keeps you in the "flow zone"

6. **🗺️ Memory Strength Mapper**
   - Tracks memory retention
   - Schedules reviews optimally
   - Reinforces weak areas

7. **🔬 Error Intelligence Classifier**
   - Analyzes types of mistakes
   - Identifies knowledge gaps
   - Provides targeted remediation

8. **👻 Invisible Personalization Engine**
   - Seamless, automatic adaptation
   - No manual settings required
   - Pure learning experience

## 🚀 Quick Start

### For Users (Just Use the App)

#### Option 1: Install APK
1. Download `EduFlow.apk`
2. Enable "Install from Unknown Sources"
3. Install the app
4. Create account and start learning!

#### Option 2: Use as PWA (Web App)
1. Visit the web URL
2. Click "Install" in browser menu
3. Use as a native app!

### For Developers (Build the App)

#### ⚡ Super Quick (3 minutes)

**Windows:**
```bash
./build-apk.bat
```

**Mac/Linux:**
```bash
chmod +x build-apk.sh
./build-apk.sh
```

Done! APK will be at `android/app/build/outputs/apk/debug/app-debug.apk`

#### 📚 Detailed Guide
See [MOBILE_APP_QUICKSTART.md](MOBILE_APP_QUICKSTART.md) for step-by-step instructions.

## 🏗️ Build Android APK

### Prerequisites
- Node.js 18+
- pnpm (auto-installed by scripts)
- Android Studio
- Java JDK 17+

### Build Steps

```bash
# 1. Install dependencies
pnpm install

# 2. Build web app
pnpm build

# 3. Sync to Android
pnpm build:android

# 4. Open Android Studio
pnpm cap:open:android

# 5. In Android Studio:
# Build → Build Bundle(s) / APK(s) → Build APK(s)
```
